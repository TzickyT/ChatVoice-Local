# Twitch and Kick do not publish an official banned-word list, so this is a starter list built from the categories
# their rules and moderators act on: slurs, hate symbols, self-harm and violence, sexual content, harassment,
# doxxing and chat spam.
#
# BASE WORDS ONLY. ChatVoice Local already catches capitals, stretched letters, spaced or dotted letters,
# number/symbol swaps, look-alike letters, censoring (f**k) and endings (s, ed, er, ing ...), so variants are not listed.
#
# Short words can catch innocent ones. If something harmless gets blocked, add it as a line like:  -word
# (an allowed word) or write the blocked one as:  =word  (exact match only).
# Delete any line you do not want. Words in this file are NEVER read aloud; to hear a different word instead,
# use replacements.txt (and do not list the same word in both: block wins).
